#flashcards/clientserver 
***
***Расшифровка:*** Application Programming Interface.
Интерфейс (стык) взаимодействия между программами. Набор готовых кнопок или правил, с помощью которых одна программа может общаться с другой.
- ***Аналогия*** - в доме много разной техники, но есть розетка - единый формат, который дает ток любому железу.
- Нужен для того, чтобы все запросы к обработчику приходили в едином формате.
***
***Примеры.***
1. ***[[Клиент Серверная Архитектура|Клиент-серверное]] API.***
	- [[Сервер (Клиент Серверная Архитектура)|Сервер]] выставляет наружу API - например [[Домен|домен]].
	- [[Клиент (Клиент Серверная Архитектура)|Клиент]] отправляет туда какой-то [[Протокол HTTP|HTTP]]-[[Методы (запросы) HTTP|запрос]] при этом не зная, как именно построена БД, [[Паттерн Repository (Репозиторий)|репозиторий]] и тд.
2. ***[[Docker]] API - [[Docker Engine API]].***
	- Когда мы через [[Терминал, Эмулятор терминала|терминал]] пишем команду, мы не управляем [[Контейнер|контейнером]] напрямую. Вместо этого утилита делает запрос к Docker API (внутренняя служба [[Docker Daemon]]).
